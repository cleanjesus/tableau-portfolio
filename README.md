## How to open the workbooks

1. Install [Tableau Public](https://public.tableau.com/app/discover) (free) or Tableau Desktop.
2. Download the `.twbx` / `.twb` file from a project folder.
3. `.twbx` files are packaged and open as-is. For the `.twb` file, keep the files in its `data/` folder and re-point the data source if Tableau asks.
