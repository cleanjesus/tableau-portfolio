# Hospital Performance

Tableau analysis of hospital operations: revenue, patient visits, and time to service across branches and departments, compared against goals.

## Business question
Which hospital branches and departments are meeting revenue and service-time goals, and where are the gaps?

## Data
- [`data/Hospital Visits.csv`](data/Hospital%20Visits.csv): about 6,300 visits with admit and discharge dates, doctor, branch, department, patient risk profile, revenue, and minutes to service.
- [`data/Hospital Goals.xlsx`](data/Hospital%20Goals.xlsx): target values used for comparison.
- Class-provided dataset with fictional patient and doctor names.

## Files
- [`hospital-performance.twb`](hospital-performance.twb): Tableau workbook. It reads the files in `data/`; if Tableau reports missing files, use *Edit Data Source* and point to them.
